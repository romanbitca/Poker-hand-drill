# Poker Hand Drill

Quiz for memorizing the 10 poker hand rankings. Works offline after the first visit.

Games: Name the hand, Hold'em (5 table + 2 hole cards), Which wins, Position to hand, Hand to position, Mixed.

Install on iPhone: open the Pages URL in Safari, Share, Add to Home Screen. Open it once online, then it runs offline.

To ship an update: edit `index.html` and bump `CACHE` in `sw.js` (for example `hand-drill-v4`), so installed copies pick up the new version.
